# Использование skills Hermes

## Основной набор

- `agent-vault`: читать и изменять агентский Obsidian vault.
- `google-workspace`: переиспользовать команды через отдельный адаптер с узкими
  OAuth scope для Calendar, Contacts и экспорта в Google Docs через `drive.file`;
  штатный setup с Gmail и полным Drive не запускать.
- `ocr-and-documents`: извлекать содержимое PDF и сканов перед сохранением.
- `llm-wiki`: синтезировать только одобренные источники в существующем vault.
- `youtube-content`: получать расшифровки и структуру видео.
- `maps`: искать места и маршруты по явно переданному местоположению.
- `blogwatcher`: отслеживать только явно выбранные RSS/Atom-источники.
- `excalidraw`: создавать свободные схемы; канонические технические диаграммы
  сохранять как Mermaid рядом с ADR в Git.

## Границы

1. Obsidian vault остаётся источником истины для задач, проектов, контактов и знаний.
2. Google Calendar остаётся источником истины для событий с фиксированным временем.
3. Google Docs содержит только экспортные копии; исходная заметка остаётся в Obsidian.
4. Не создавать отдельные `~/wiki`, JSON-базы задач или другие хранилища памяти.
5. Не изменять встроенные skills: проектные правила оформлять отдельным адаптером.
6. Не устанавливать community skills без inspect, security scan и ручного просмотра.
7. Не использовать `--force` для обычного обхода предупреждений безопасности.
