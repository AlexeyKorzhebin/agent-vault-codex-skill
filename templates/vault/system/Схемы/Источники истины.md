# Источники истины

| Данные | Каноническое хранилище |
|---|---|
| проекты, задачи, контакты, пользовательский контекст | Obsidian vault |
| события с фиксированным временем | Google Calendar |
| экспортированные идеи | Google Docs как производная копия Obsidian-заметки |
| конфигурация сервисов, ADR, runbooks и технические диаграммы | Git |
| запущенные процессы, runtime-данные и журналы | VPS |
| пароли, токены, ключи и содержимое `.env` | защищённое хранилище секретов |

Vault и Git не синхронизируются напрямую. Hermes связывает их полями заметки:
`repository`, `repository_path`, `deployed_commit` и `architecture_decisions`.
Конфигурационные файлы не копируются в vault.
