# Правила vault

## Распределение

- Одноразовый разговор: ответить без сохранения.
- Понятное действие: добавить задачу в соответствующий проект или область.
- Результат из нескольких шагов: создать или обновить проект.
- Постоянная ответственность: обновить область.
- Справочный материал: сохранить в Ресурсы.
- Большой материал с неясным назначением: сохранить во Входящие и уточнить применение.

## Встроенные помощники

- Перед обработкой PDF или скана использовать `ocr-and-documents`, затем сохранить
  результат через `agent-vault`.
- Перед обработкой YouTube использовать `youtube-content`, затем сохранить исходную
  расшифровку и согласованную выжимку через `agent-vault`.
- Для мест, координат и маршрутов использовать `maps`; не сохранять геопозицию без
  долговременной пользы.
- Для синтеза знаний использовать `llm-wiki` только через проектный адаптер путей;
  не создавать отдельный `~/wiki`.
- Для Calendar, Contacts, Google Docs и Drive использовать отдельный адаптер к
  `google-workspace` с собственным OAuth-клиентом и минимальными scope. Ограничить
  Drive scope значением `drive.file`; не подключать Gmail и полный Drive. События
  с участниками, публикацию документов и предоставление доступа создавать только
  после подтверждения пользователя.

## Подтверждение

Запрашивать подтверждение перед удалением, массовым перемещением, внешней отправкой,
изменением календарной встречи, финансовой операцией или изменением сервера вне
утверждённого плана.

## Проверка

После записи прочитать тот же путь. Для важного материала также вывести родительскую
папку. Не сообщать об успехе только на основании нулевого кода выхода конвейера.
